# Experiment Matrix

Matriks final dibentuk secara programatis dari:

- 15 lokasi tervalidasi dari `configs/locations.yaml`;
- polutan `co` dan `co2`;
- `scenario_1` dan `scenario_2`;
- `xgboost` dan `lightgbm`.

Total yang diharapkan setelah daftar lokasi tersedia adalah 120 eksperimen. Jangan menulis kombinasi tersebut sebagai file kode terpisah. Status setiap kombinasi disimpan oleh experiment registry.
